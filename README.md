# RemiDeck

Aturan, papan skor, dan game kartu lawan Bot. Capsa Banting bisa mabar online lewat link.

Langkah pasang di GitHub Pages:
1. Upload `index.html`, `.nojekyll`, dan `README.md` ke repo (branch `main`).
2. Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
3. Buka `https://USERNAME.github.io/NAMA-REPO/`.
